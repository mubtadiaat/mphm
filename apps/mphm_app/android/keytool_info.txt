====================================================================
🔑 PANDUAN LENGKAP SHA-1 & SHA-256 FIREBASE GOOGLE SIGN-IN
====================================================================

1. APAKAH NILAI SHA-1 & SHA-256 BERGANTI SAAAT BUILD DI GITHUB ACTIONS?
   - Ya, jika build Android menggunakan Keystore bawaan lingkungan CI/CD.
   - OLEH KARENA ITU, GitHub Actions workflow (.github/workflows/release.yml & build-flutter.yml)
     telah dikonfigurasi untuk OTOMATIS mengekstrak dan menampilkan nilai SHA-1 dan SHA-256 
     langsung di tab "Summary" halaman GitHub Actions setiap kali build selesai!

2. CARA MENGAMBIL NILAI SHA DARI GITHUB ACTIONS SUMMARY:
   a. Buka Repository GitHub -> Tab "Actions".
   b. Klik workflow run terbaru ("Build Release Android Binary").
   c. Pada bagian "Summary", scroll ke bawah ke kotak:
      "🔑 Android Signing Fingerprints (Salin ke Firebase Console)"
   d. Salin nilai SHA-1 dan SHA-256 tersebut.

3. CARA MEMATENKAN SHA (RELEASE KEYSTORE) SUPAYA TIDAK PERNAH BERGANTI:
   Jika Anda ingin nilai SHA-1 & SHA-256 TETAP PATEN SELAMANYA:
   a. Buat Release Keystore permanent dengan perintah terminal:
      keytool -genkey -v -keystore apps/mphm_app/android/app/upload-keystore.jks -storetype JKS -keyalg RSA -keysize 2048 -validity 10000 -alias upload
   b. Dapatkan SHA-1 & SHA-256-nya:
      keytool -list -v -keystore apps/mphm_app/android/app/upload-keystore.jks -alias upload
   c. Masukkan nilai SHA-1 & SHA-256 tersebut ke Firebase Console:
      Firebase Console -> Project Settings -> General -> Your Apps -> Add Fingerprint.
   d. Simpan file `upload-keystore.jks` secara rahasia sebagai Secret di GitHub (`KEYSTORE_BASE64`).
